# Sprint 2.3 Collection Checklist

## Before Recording
- [ ] Camera works with `--camera-index 1`.
- [ ] Background is clean.
- [ ] Lighting is bright and stable.
- [ ] Hand is clearly visible.
- [ ] Participant ID is `P02`.
- [ ] Trial commands or dry-run output are reviewed.

## During Recording
- [ ] Each label is recorded 5 times.
- [ ] Videos save correctly after each recording.
- [ ] Metadata updates after each successful recording.
- [ ] Bad recordings are re-recorded.
- [ ] No landmark extraction is started.
- [ ] No model training is started.

## After Recording
- [ ] Raw video folders contain the trial videos.
- [ ] `ml/metadata.csv` contains the trial rows.
- [ ] `check_trial_dataset.py` passes.
- [ ] Evidence screenshots are saved.

## Evidence Screenshots To Capture
- [ ] `run_trial_collection.py --dry-run` output.
- [ ] Webcam recording with clear hand visible.
- [ ] Raw video folders after recording.
- [ ] `metadata.csv` after trial recording.
- [ ] `check_trial_dataset.py` pass output.
- [ ] `sprint_2_3_trial_dataset_check.md` report.
